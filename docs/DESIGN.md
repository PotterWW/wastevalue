# DESIGN — หน้าตาเว็บ

ต้นฉบับ: `design/Main.dc.html` (ไฟล์อ้างอิงจากเครื่องมือออกแบบ **ไม่ใช่โค้ดที่ใช้จริง** ต้องรันผ่าน runtime ของเครื่องมือนั้น)
งานคือเขียน `web/index.html` ใหม่ด้วย HTML/CSS/JS ล้วน **ลอกค่าสี ฟอนต์ ระยะ มุมโค้ง เงา และ layout ให้ตรงต้นฉบับ** ค่าทั้งหมดอยู่ใน `style="..."` และ `<helmet><style>` ของไฟล์ต้นฉบับ

## ฟอนต์
- หัวข้อ ปุ่ม ตัวเลข: `'Prompt'` 500/600/700
- เนื้อความ: `'Noto Sans Thai'` 400/500/600
- fallback: `system-ui, sans-serif`

## รูปทรง
- ปุ่มและป้าย: `border-radius: 999px` ปุ่มหลักสูง 56px
- การ์ดใหญ่ 32px / การ์ดย่อย 22–28px / กล่องข้อมูลย่อย 16px
- เงาการ์ด: `0 12px 40px rgba(18,59,42,.08)`
- ความกว้างเนื้อหา 1160px (ส่วนอัปโหลด 880px) gutter 24px
- section เว้นบนล่าง 88px, hero มุมล่างโค้ง 48px, section ผลลัพธ์มุมบนโค้ง 48px

## Animation (มีแล้วในต้นฉบับ ใช้ต่อ)
`wv-scan` เส้นสแกนตอนวิเคราะห์, `wv-spin`, `wv-float` การ์ดลอยใน hero — ปิดเมื่อ `prefers-reduced-motion`

## สิ่งที่ต้องเปลี่ยนจากต้นฉบับ
1. **การ์ดผลลัพธ์ทำเป็นเทมเพลตเดียวที่เติมจาก API** แทนการเขียน 3 ตัวอย่างตายตัว ครบ 6 สถานะตาม `docs/SPEC.md`
   - รีไซเคิล → ใช้แบบ "ขวด PET" (การ์ดราคา + ช่องน้ำหนัก + ถังรีไซเคิล)
   - ทั่วไป → ใช้แบบ "ซองขนม" (สีเทา)
   - อันตราย → ใช้แบบ "ถ่านไฟฉาย" (กรอบส้ม)
   - **ติดเชื้อ (ใหม่)** → ใช้โครงเดียวกับอันตราย เปลี่ยนไอคอนและข้อความ
   - **อินทรีย์ (ใหม่)** → โครงเดียวกับทั่วไป แต่ใช้โทนเขียว ไอคอนใบไม้
   - **ไม่แน่ใจ (ใหม่)** → การ์ดโทนเทา ไอคอนเครื่องหมายคำถาม แสดง 2 คำตอบที่เป็นไปได้ + เคล็ดลับการถ่าย
2. **ลบคำว่า "PET"** ทุกที่ (การ์ดลอยใน hero ใช้ "พลาสติก") และลบ "Multi-layer Plastic"
3. **ราคาเป็น `null` ได้** → แสดง "ยังไม่มีข้อมูลราคา" และซ่อนช่องน้ำหนัก
4. **"อัปเดตราคาเมื่อ"** แสดงจาก `price_date` + `price_source` ถ้าไม่มีให้ซ่อนบรรทัดนั้น
5. **ปุ่มตัวอย่างและข้อความ "โหมดสาธิต"** ซ่อนไว้ แสดงเฉพาะเมื่อ URL มี `?demo`
6. **Waste Guide** เหลือ 5 การ์ดตามประเภทขยะ ใช้ `guide_examples` จาก `data/categories.json` (ฝังไว้ใน JS ได้)
7. เพิ่มคำแนะนำการถ่ายใต้ช่องอัปโหลด: "ขยะ 1 ชิ้น · พื้นหลังเรียบ · แสงพอ"
8. **สีถังในไอคอน** ต้นฉบับวาดถังรีไซเคิลเป็นสีเขียว ให้เปลี่ยนให้ตรง `data/categories.json` (รีไซเคิล = เหลือง, อินทรีย์ = เขียว, ทั่วไป = น้ำเงิน, อันตราย = แดง) หลังทีมยืนยันสีแล้ว
