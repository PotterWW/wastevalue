# SPEC — สิ่งที่ระบบทำ

## เป้าหมาย
ผู้ใช้ถ่ายรูปขยะ 1 ชิ้น อัปโหลด แล้วได้คำตอบ 4 อย่าง:
1. **ประเภทขยะ** (5 ประเภท): ทั่วไป / อินทรีย์ / รีไซเคิล / อันตราย / ติดเชื้อ
2. **วัสดุ** (สำหรับขยะรีไซเคิล): กระดาษ กล่องกระดาษ โลหะ พลาสติก แก้ว 3 สี
3. **ราคารับซื้อโดยประมาณ** ต่อกิโลกรัม (เฉพาะที่ขายได้) + คำนวณมูลค่าจากน้ำหนักที่ผู้ใช้กรอก
4. **คำแนะนำ** ก่อนขายหรือก่อนทิ้ง และควรทิ้งถังไหน

## ขอบเขต (Main Scope)
- เว็บ 1 หน้า เลื่อนลงมาดูผล (ดีไซน์เดิมเป็นหน้าเดียวยาว ใช้ตามนั้น)
- รองรับไฟล์ JPG / PNG ไม่เกิน 10 MB รูปละ 1 ชิ้น
- รันบน localhost ตอนนำเสนอ

## ไม่อยู่ในขอบเขต (ใส่ในสไลด์ "แนวทางต่อยอด")
- แยกชิ้นส่วนขยะหลายชิ้นในภาพเดียว (เช่น แก้ว + หลอด + ฝา)
- ระบุสภาพขยะ (มีน้ำค้าง เปื้อนอาหาร)
- ราคาต่อชิ้น / ประมาณน้ำหนักจากภาพ
- กล้องแบบเรียลไทม์
- ระบบสมาชิก ฐานข้อมูล การ deploy

### Upload
- ลากวางหรือกดเลือกไฟล์ → แสดงภาพตัวอย่าง → ปุ่ม "วิเคราะห์ด้วย AI"
- ระหว่างรอ: เส้นสแกนบนภาพ + ข้อความ "AI กำลังวิเคราะห์..."
- ใต้ช่องอัปโหลดมีคำแนะนำการถ่าย: ขยะ 1 ชิ้น พื้นหลังเรียบ แสงพอ
- error: ไฟล์ผิดชนิด, ใหญ่เกิน, ยังไม่เลือกรูป, server ไม่ตอบ → ข้อความบอกว่าเกิดอะไรและต้องทำอะไร

### Result — 6 สถานะ (เลือกจาก `category` และ `uncertain` ใน response)
| สถานะ | เงื่อนไข | เนื้อหา |
|---|---|---|
| รีไซเคิล ขายได้ | `category = recyclable` | ชื่อ วัสดุ ป้าย "ขายได้" ราคา/กก. ช่องกรอกน้ำหนัก → มูลค่าโดยประมาณ, คำแนะนำก่อนขาย, ถ้าไม่ขายทิ้งถังไหน |
| ขยะทั่วไป | `category = general` | ป้าย "ขายไม่ได้" คำแนะนำ (เสื้อผ้า/รองเท้า: บริจาคเป็นข้อแรก) ถังที่ควรทิ้ง |
| ขยะอินทรีย์ | `category = organic` | คำแนะนำทำปุ๋ย/แยกน้ำ ถังที่ควรทิ้ง |
| ขยะอันตราย | `category = hazardous` | กรอบเตือนสีส้ม "ห้ามทิ้งรวมกับขยะทั่วไป" คำแนะนำ จุดรับทิ้ง |
| ขยะติดเชื้อ | `category = infectious` | กรอบเตือนแบบเดียวกับอันตราย ห่อมิดชิด ใส่ถุงแยก เขียนป้าย |
| ไม่แน่ใจ | `uncertain = true` | ไม่ฟันธง แสดง 2 คำตอบที่เป็นไปได้ + วิธีถ่ายใหม่ |

ทุกสถานะ (ยกเว้นไม่แน่ใจ) แสดง: ภาพที่อัปโหลด, ชื่อไทย, แถบความมั่นใจ %, ถ้าความมั่นใจ < 0.8 แสดงคำตอบอันดับ 2 เล็กๆ
